# Шахи

Легка браузерна шахова гра українською мовою з комп'ютерним суперником. Проєкт оформлений у стриманому класичному стилі: тепла палітра, фактура паперу, дерев'яні кольори дошки та виразна типографіка.

## Можливості

- Гра проти комп'ютера з п'ятьма рівнями складності.
- Вибір кольору фігур, за які грає користувач.
- Легальні ходи, шах, мат і пат.
- Рокірування, взяття на проході та автоматичне перетворення пішака на ферзя.
- Скасування ходу та початок нової партії.
- Перетягування фігур або керування кліками.
- Налаштування кольорів дошки та фігур, а також стилю фігур.
- Збереження налаштувань у `localStorage`.
- Адаптивне компонування для комп'ютерів і телефонів.
- Обчислення ходів у Web Worker, якщо браузер його підтримує.
