# Шахи

Легка браузерна шахова гра українською мовою з комп'ютерним суперником. Проєкт оформлений у стриманому класичному стилі: тепла палітра, фактура паперу, дерев'яні кольори дошки та виразна типографіка.

## Можливості

- Гра проти комп'ютера з п'ятьма рівнями складності.
- Вибір кольору фігур, за які грає користувач.
- Легальні ходи, шах, мат і пат.
- Рокірування, взяття на проході та автоматичне перетворення пішака на ферзя.
- Скасування ходу та початок нової партії.
- Перетягування фігур або керування кліками.
- Налаштування кольорів дошки та фігур, а також стилю фігур.
- Збереження налаштувань у `localStorage`.
- Адаптивне компонування для комп'ютерів і телефонів.
- Обчислення ходів у Web Worker, якщо браузер його підтримує.

## Запуск локально

Найпростіше — відкрити `index.html` у сучасному браузері.

Або запустити локальний HTTP-сервер у каталозі проєкту:

```bash
python -m http.server 8000
```

Потім відкрити <http://localhost:8000>.

## Публікація через GitHub Pages

1. Створи на GitHub новий репозиторій, наприклад `chess`.
2. Завантаж у нього `index.html`, `README.md`, `LICENSE` та `.gitignore`.
3. Відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери **Deploy from a branch**.
5. Вкажи гілку `main` і папку `/ (root)`, потім натисни **Save**.

Після публікації гра буде доступна за адресою GitHub Pages твого репозиторію.

## Відомі обмеження

- Гра розрахована на локальну партію проти комп'ютера; мережевого мультиплеєра немає.
- Перетворення пішака виконується автоматично на ферзя.
- Налаштування зберігаються в браузері на цьому пристрої.

## Технології

HTML, CSS і JavaScript без сторонніх бібліотек. Шрифти використовують системні резервні варіанти, тому гра не залежить від зовнішнього CDN.
